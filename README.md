# Fletcher Mines — Institutional Mining Platform

An institutional hash-rate allocation and cloud mining platform built on Next.js 16, React 19, and SQLite.

## Overview
- **Exclusive Network**: TRON (TRC-20) exclusive deposits and payouts (`TKesHy9pJLnK3HkdZkREJzwuo9by1CYXEr`).
- **Telegram Onboarding**: Mandatory verification joining 90,000+ active miners (`https://t.me/gomining`).
- **Withdrawal Conditions**: Minimum withdrawal threshold of 1,000.00 USDT. Accounts with capital locked in active mining contracts cannot withdraw until all contracts reach full maturity at the end of the run.
- **Yield Distribution**: Tiered fixed daily yield credited at 00:00 UTC daily.
- **Admin Gateway**: Master-gated security console with real-time treasury management and user oversight.

## Local Development
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portal.
